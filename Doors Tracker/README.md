# DOORS Tracker

Unofficial DOORS development and update tracker.

## Structure

- `index.html` — main application
- `styles.css` — website styling
- `app.js` — application logic
- `data.js` — current website data
- `assets/` — DOORS artwork and developer images
- `data/` — structured JSON data
- `pages/` — future standalone page templates
- `.github/workflows/` — automated update checks

## Images

Place properly sourced/credited DOORS artwork in the appropriate
`assets/` folder.

Do not claim fan-made artwork as official artwork.

## Updating The Archives

Change:

`data.js`

and update:

`nextUpdate.date`

The countdown automatically recalculates.

## Development credits

Only add people when their contribution can be supported by a public
credit/source.

## Deployment

This project can be hosted using GitHub Pages because the frontend is
static.

DOORS Tracker
